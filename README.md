(standard numeric format) :: هو عباره عن ازاي بتحكم في عرض الناتج 
وعندي طريقتين الاولي هي ال موجوده في التاسك ال هي :
$"Equation: {X} + {Y} = {X + Y:C}" 
ال هي بعمل : وبكتب c ودي بتحولها ل currency يعني عمله عشان كدا الناتج طلع بالدولار 30.00$ 
وفيه عندي طريقه تانيه زي انا عايز اطلع الناتج دا هعمل .ToString("c")
$"Equation: {X} + {Y} = {(X + Y).ToString("c")}" ;
وممكن تتكتب capital او small عاادي 
وممكن اعرضها عباره عن رقم صحيح عن طريق d: decimal point او ميه في الميه p: percentage او n: number 
ولو عايز اقربه لعلامه عشريه معينه بحط f: fixed point وبقدر اتحكم في الارقام ال بعد العلامه عن طريق f0 مفيش ارقام بعد العلامه , f1 رقم واحد بعد العلامه , f2 رقميين وهكذا ..
